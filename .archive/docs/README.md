# Archive Docs

이 폴더는 `abuts.fit`의 **아카이브 문서 보관소**입니다.

## 1. 보관 대상

- 과거 작업 요약 문서
- 완료된 리팩터링 기록
- 오래된 설계 문서
- 임시 운영 메모
- 현재 기준 문서가 아닌 성능/테스트/실험 문서

## 2. 문서 기준

- 이 폴더의 문서는 **현재 기준 문서가 아닙니다.**
- 실제 동작 기준은 **코드와 루트 `rules.md`** 입니다.
- 내용이 현재 코드와 다르면 **코드가 우선**입니다.

## 3. 분류 원칙

- **규칙 문서**: 루트 `rules.md`, 하위 `rules.md`
- **운영 문서**: README, 운영 가이드, 스크립트 사용 문서
- **API 문서**: `web/backend/docs/*` 같은 레퍼런스 문서
- **히스토리 문서**: 이 폴더로 이동한 과거 요약/설계/메모 문서

## 4. 파일명 규칙

- 가능한 한 짧고 설명적인 kebab-case를 사용합니다.
- 예:
  - `backend-optimization-summary.md`
  - `frontend-performance-optimization-guide.md`
  - `bridge-api-design.md`

## 5. 정리 원칙

- 새 문서가 현재 기준이라면 원래 위치에 둡니다.
- 기준 문서가 아니게 되면 이 폴더로 이동합니다.
- 중복 문서는 최신 하나만 남기고 나머지는 이동 또는 삭제합니다.
